### How I test in the app

1. `npm run desktop`. Every roster avatar is painted in its agent's colour (ring + mascot body) and the chat header shows the same colour for the selected agent. Two agents created with different colours look different.
2. Hover an agent → **…** → **Edit profile**. Change the name, job, description, mascot and colour → **Save**. The row and header repaint at once; on disk `agents/{NewName}/agent.json` has the new `color` / `job` / `mascotId`, `AGENTS.md` starts `# NewName`, then the job, then your description; the old folder is gone; the chat history is still there.
3. At the bottom of the roster click **New section**, type a name, Enter. Hover an agent → **…** → under **Section** pick it: the agent moves under the heading. Search still finds agents in any section; while searching, empty headings hide. Quit the app, delete the browser storage (or simply `localStorage.clear()` in DevTools) and relaunch: the sections and the filing are still there — they live in `localbot-agents.json` next to the config.
4. Click **+ New agent** (not the slider button). A chat opens on "New agent — Setting up" and the agent asks what to call it. Answer the name, then the job, then standing instructions (or `skip`). A grey line says what was saved; the roster shows the new name and job; `agents/{Name}/` exists with agent.json + AGENTS.md; the composer now reads "Message {Name}" and the next message is a normal turn.
5. Click the slider button next to **+ New agent**: the old New agent form opens (name, job, mascot, colour, model, scopes) and still creates the agent the same way.
